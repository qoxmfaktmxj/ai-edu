GitHub 연결 확인

내 PC의 Claude Code가 내 GitHub 저장소와 잘 연결되어 있는지 확인합니다.

약 10분난이도 쉬움

연결 확인하기

2장에서 GitHub 가입, 저장소 만들기, 내려받기를 마쳤습니다. 이제 Claude 앱의 Code 탭에서 ai-site 폴더를 연 세션에 아래처럼 부탁해 연결이 잘 됐는지 확인합니다. 이 폴더는 4장부터 계속 쓰는 작업 폴더입니다.

주소가 https://github.com/[내 사용자 이름]/ai-site.git으로 보이고 오류가 없으면 연결 완료입니다. 오류가 나면 2장의 "자주 막히는 곳"을 먼저 확인하세요.

막혔을 때

회사 PC에서 연결이 막히거나 인증서 오류가 납니다

회사 네트워크의 보안 장비(프록시, 방화벽)가 GitHub 접속이나 SSH 통신을 막는 경우가 있습니다. 오류 문구를 메모해 두고 사내 IT 담당자에게 "github.com 접속과 gh 로그인이 필요한 교육 실습인데 막히는 것 같다"고 문의하세요. 이런 경우 개인 PC나 집 네트워크에서 먼저 진행해 보는 것도 방법입니다.

올리기가 "Permission denied" 또는 403 오류로 실패합니다

PowerShell에서 gh auth status를 입력해 로그인 상태를 먼저 확인하세요. 로그인이 풀려 있으면 gh auth login을 다시 하면 됩니다. 저장소 이름이 이미 다른 곳에서 쓰이고 있다면 ai-site-2처럼 다른 이름을 Claude에게 알려 주세요.
