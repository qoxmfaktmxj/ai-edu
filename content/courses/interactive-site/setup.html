준비: 설치, 저장소, 배포 연결, 스킬

도구를 설치하고, 빈 저장소를 만들어 Claude 앱에서 열고, Vercel에 연결해 첫 배포를 한 뒤, 디자인과 모션 스킬을 넣습니다. 이미 있는 것은 건너뜁니다.

Mac은 Git이 git --version 첫 실행 때 개발자 도구 설치 안내로 함께 들어오고, 나머지는 각 공식 사이트나 Homebrew로 설치합니다. 설치 뒤에는 터미널을 새로 엽니다.

회사망에서 Node 기반 도구가 인증서 오류를 낼 때

회사망이 TLS를 중간에서 검사하면 npx, vercel 같은 Node 도구가 SELF_SIGNED_CERT_IN_CHAIN 오류로 실패할 수 있습니다. 설치는 되는데 실행할 때 실패하는 경우가 많습니다. 아래처럼 Node가 Windows 인증서 저장소를 쓰게 하고 터미널을 새로 엽니다.

1. 저장소 만들고 내려받기

사이트용 비공개 저장소 ai-site를 만들고 문서 폴더에 내려받습니다. gh auth login은 브라우저로 GitHub 로그인을 승인하는 방식(HTTPS)을 고르면 됩니다.

비공개 저장소도 Vercel Hobby 플랜으로 배포할 수 있습니다. 배포된 사이트 주소는 누구나 열 수 있습니다.

2. Claude 앱에서 폴더 열기

  1. Code 탭, Local, Select folder

    Claude 앱의 Code 탭에서 실행 환경을 Local로 두고 Select folder로 ai-site를 엽니다. 이 폴더가 작업 폴더이고, Claude는 이 안에서 파일을 읽고 고치고 명령을 실행합니다.

  2. 모델과 노력 수준

    이 교육은 Opus 5.5, 노력 수준 Extra high 기준입니다. 새 세션을 시작할 때 고르고, 대화 중에는 바꾸지 않습니다. 대화 중에 모델을 바꾸면 지금까지의 대화를 다시 읽느라 사용 한도를 더 씁니다.

  3. 권한 모드

    입력창 옆 선택기에서 Claude가 묻지 않고 해도 되는 범위를 정합니다. 이 교육은 Accept edits로 합니다.

    모드동작쓰는 때
    Manual파일 수정과 명령 실행 전에 매번 diff나 명령을 보여 주고 묻습니다.회사 저장소, 처음 보는 코드
    Accept edits작업 폴더 안의 파일 수정, 폴더 만들기, 이동은 묻지 않고, 그 밖의 명령은 묻습니다.이 교육의 기본
    Plan읽고 조사해서 계획만 제안하고 파일은 고치지 않습니다.큰 변경 전
    Auto별도 검사기가 위험한 동작을 걸러 주고 나머지는 묻지 않습니다. 계정과 모델에 따라 없을 수 있습니다.익숙해진 뒤
    Bypass permissions모든 확인을 건너뜁니다. 설정에서 켜야 보이고, 회사 계정은 조직 정책이 정합니다.쓰지 않음

  4. 터미널에서도 쓰려면 (선택)

    앱의 Code 탭에 Claude Code가 들어 있어 이 교육은 앱만으로 충분합니다. 터미널의 claude 명령도 쓰려면 공식 문서의 네이티브 설치를 따르고 claude --version으로 확인합니다. 앱과 터미널은 설정과 스킬을 함께 씁니다.

3. Vercel 연결과 첫 배포

빈 저장소는 배포할 것이 없으므로 먼저 한 장짜리 페이지를 올립니다.

  1. 가입

    vercel.com/signup에서 Continue with GitHub로 가입하고, 플랜을 물으면 Hobby를 고릅니다. Hobby는 개인, 비상업 용도 전용입니다. 이 방법으로 만든 사이트를 업무나 영업에 쓰려면 사내 정책과 Vercel 이용 조건을 먼저 확인합니다.

  2. Import와 Deploy

    Add New..., Project에서 GitHub 저장소 목록을 엽니다. 처음이면 Vercel GitHub App을 설치하라고 나오는데, 접근 범위는 Only select repositories로 ai-site만 고릅니다. ai-site를 Import하고 Framework Preset은 Other, 나머지는 기본값으로 두고 Deploy를 누릅니다. 프로젝트 이름이 주소가 되므로 실명이나 회사명은 넣지 않습니다.

  3. 주소 확인

    프로젝트 화면의 Domains에 있는 https://[프로젝트이름].vercel.app을 열고, 휴대폰에서도 열어 봅니다.

푸시한 곳배포누가 열 수 있나
mainProduction. 내 사이트 주소가 바뀝니다.누구나
다른 브랜치Preview. 브랜치마다 따로 미리보기 주소가 생깁니다.기본 설정에서는 Vercel에 로그인한 나만 (Settings, Deployment Protection에서 확인)

4장에서는 이 차이를 이용해 브랜치에서 다듬고 미리보기 주소로 비교한 뒤 main에 합칩니다.

스킬과 플러그인은 내 권한으로 실행되는 제3자 코드입니다. 설치 전에 무엇이 실행되는지 확인합니다.

플러그인 두 개는 앱 화면에서 설치합니다. 입력창의 +, Plugins, Add plugin에서 마켓플레이스 nextlevelbuilder/ui-ux-pro-max-skill과 heygen-com/hyperframes를 추가하고, 목록의 ui-ux-pro-max와 hyperframes를 설치합니다. 설치 전에 플러그인이 넣는 훅과 MCP 서버가 무엇인지 저장소에서 확인합니다. 터미널의 Claude Code를 쓴다면 /plugin 메뉴에서 같은 일을 합니다.

설치한 것은 새 세션(Ctrl+N)에서 목록에 나타납니다. 입력창에 /를 쳐서 네 이름이 보이는지 확인합니다.
