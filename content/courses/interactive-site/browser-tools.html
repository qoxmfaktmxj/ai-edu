내 업무에 맞는 브라우저 자동화

Aside, ego lite, Playwright, Computer Use가 무엇을 해결하는지 알아봅니다. 조사, 반복 검증, 여러 사이트 작업, 데스크톱 업무 중 내가 자주 하는 일을 기준으로 도구를 고릅니다. 설명 15분, 실습과 토론 15분을 권장합니다.

같은 부탁도 작업 환경에 따라 달라집니다

“이번 달 서비스 이용 요금을 비교해 줘”라는 부탁을 생각해 봅시다. 매번 다른 사이트를 읽고 조건을 해석하는 일과, 같은 페이지의 같은 항목을 매일 확인하는 일은 다릅니다. 웹에서 찾은 결과를 설치형 프로그램에 입력하는 일까지 포함되면 필요한 도구도 달라집니다.

이 장의 목표는 제품 이름을 외우는 것이 아닙니다. 어디에서 일을 시작하는지, 무엇을 조작하는지, 같은 절차를 얼마나 반복하는지를 설명하고 알맞은 방식을 선택하는 것입니다.

Space, 로그인, 병렬 작업은 따로 봅니다

ego lite의 Space는 사람과 에이전트, 여러 작업의 탭을 분리해 관리하도록 돕습니다. 기존 로그인 상태를 활용하는 것과 작업 탭을 나누는 것은 서로 다른 기능입니다. Space를 나눴다고 계정 권한이나 서버 데이터까지 격리됐다고 판단하면 안 됩니다. 두 작업이 같은 업무 데이터를 수정하면 충돌할 수 있습니다. ego lite 공식 설명

Playwright도 별도 브라우저 컨텍스트, 병렬 테스트, 창을 띄우지 않는 실행을 지원합니다. ego lite의 비교 포인트는 병렬 실행의 독점 여부보다, 일상 브라우저에서 에이전트 작업을 관리하는 경험입니다. 컨텍스트 격리

토큰이 적은 도구보다 완료 비용을 비교합니다

페이지 관찰 → 다음 행동 판단 → 실행 → 결과 확인을 반복하면 관찰량과 재시도 횟수가 비용에 영향을 줍니다. 여러 동작을 코드로 묶고 필요한 값만 반환하면 왕복을 줄일 수 있지만, 판단이 필요한 중간 결과까지 생략하면 오류를 놓칠 수 있습니다.

영상의 ego lite 비용 비교는 개발사가 공개한 31개 작업 벤치마크를 소개한 것입니다. 모든 사이트에서 가장 저렴하다는 보장은 아닙니다. 모델, 작업 난도, 성공 판정, 재시도 조건이 같은지 확인하고 자신의 업무로 시험합니다.

측정 항목확인 방법
완료율필수 조건을 모두 충족한 작업 수 / 시도한 작업 수
완료 1건당 모델 비용실패와 재시도에 쓴 모델 비용까지 합산 / 성공 건수. 성공이 0건이면 계산 불가로 기록
사람의 확인 시간출처 확인, 누락 수정, 중단 후 이어가기 등에 쓴 시간
총 소요시간준비부터 검토가 끝날 때까지의 시간

예를 들어 A가 10회 시도에 1,000원을 쓰고 5회 성공했다면 성공 1건당 200원입니다. B가 1,500원을 쓰고 10회 성공했다면 150원입니다. 이 숫자는 계산 방법을 보여 주는 가상 값이며 제품 실측치가 아닙니다.

같은 요청으로 비교하는 15분 실습

회사 데이터 대신 공개된 서비스 요금 페이지 3곳을 사용합니다. 수강생이 이용할 수 있는 방식 2개를 골라 같은 요청을 보내고, 모델과 환경이 다르면 기록합니다. 도구를 설치하지 않은 사람은 진행자의 결과를 함께 평가합니다.

2분 동안 입력과 기준을 맞추고, 8분 동안 실행한 뒤, 5분 동안 결과를 대조합니다. “표를 만들었다”가 아니라 출처와 값이 맞고 조건을 빠뜨리지 않았는지로 완료를 판단합니다. 비용 기록이 없으면 추정 숫자를 넣지 않고 미측정으로 표시합니다.

  • “Computer Use로 모든 소프트웨어를 제어한다”는 표현 대신, 연결 도구가 지원하고 권한이 있는 화면을 조작할 수 있다고 설명합니다.
