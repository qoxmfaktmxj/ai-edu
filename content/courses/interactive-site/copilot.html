Copilot만 있을 때: 설치 없이 만들고 배포하기

Claude 유료 플랜이 없고 회사의 Microsoft Copilot(예전 이름 Microsoft 365 Copilot)만 쓸 수 있는 분을 위한 길입니다. 아무것도 설치하지 않고, Copilot에게 웹페이지 파일을 받아 Vercel 화면에 끌어다 놓기만 하면 내 주소가 생깁니다.

약 30분난이도 쉬움

이 부록은 누구를 위한 길인가요

본편은 Claude Code가 내 PC에서 직접 파일을 만들고 GitHub와 Vercel까지 연결하는 방식입니다. 회사에서 Copilot만 쓸 수 있다면 그 방식을 그대로 따라 할 수 없습니다. 대신 아래 흐름으로 같은 결과물, 즉 내 주소로 열리는 웹페이지를 만들 수 있습니다.

  1. Copilot에게 부탁
  2. index.html 파일 받기
  3. 내 PC에서 열어 확인
  4. Vercel에 끌어다 놓기
  5. 주소로 열림

Copilot에서 Claude 모델을 골라도 본편처럼 안 되는 이유

Copilot 안의 GPT와 Claude는 회사가 맺은 계약(데이터 보호 약정)이 적용된 채로 일합니다. Claude는 Microsoft와 계약한 외부 업체(Anthropic)가 운영하는 모델입니다. 어느 쪽이든 대화로 파일을 만들어 줄 수는 있지만, 내 PC의 폴더에 직접 파일을 쓰거나 명령을 실행하지는 못합니다. 그래서 "만들어 주면, 내가 받아서 올리는" 순서가 됩니다.

VS Code 같은 개발 도구의 Copilot은 이름이 같아도 GitHub Copilot이라는 별도 상품이라, 회사 Microsoft Copilot 계정으로는 열리지 않습니다.

준비물

  • 회사 계정으로 로그인한 Copilot: Teams 왼쪽 앱 막대의 Copilot 또는 Microsoft Copilot 앱(예전 이름 Microsoft 365 Copilot 앱). 회사 계정으로 쓰면 회사가 정한 데이터 보호 설정이 적용됩니다.
  • Vercel 계정: 3장의 "2. Vercel 가입하기"를 따라 가입합니다. GitHub 계정이 없다면 Continue with Email로 가입하면 됩니다. 3장의 Hobby 플랜 주의 사항(개인, 비상업 용도)도 함께 읽어 주세요.
  • 브라우저: Edge 또는 Chrome
  • 파일 확장명 보기 켜기: 파일 탐색기 위쪽 메뉴에서 보기 > 표시 > 파일 확장명을 켭니다. 이 부록에서는 파일 이름 끝의 .html, .zip, .png를 눈으로 확인해야 하는 순간이 여러 번 있습니다.
보안 수칙은 본편과 같습니다

Copilot 대화창에도 1장의 입력 금지 정보(개인정보, 인증정보, 회사 기밀)를 넣지 마세요. 회사 계정이라고 해서 예외가 아닙니다. 요구사항에는 가짜 예시 내용만 적습니다.

또 Vercel에 올린 페이지는 주소를 아는 누구나 볼 수 있습니다. 페이지 안의 글, 그림, 숨은 파일에도 회사 정보나 개인정보를 넣지 마세요.

1단계: Copilot에서 모델 고르기

Copilot 대화 화면 오른쪽 위의 모델 이름을 누르면 목록이 열립니다. 화면에 따라 "자동, 빠른 응답, 깊이 생각하기" 같은 모드와 Claude, GPT 모델이 함께 보이거나, 모델마다 모드가 붙어 있을 수 있습니다. 웹페이지를 만들 때는 깊이 생각하기(또는 Think deeper)를 켜고 상위 모델(예: Claude Opus 5.5, GPT 6.1 Sol)을 고르세요. Claude가 목록에 없으면 회사 설정 때문이니 GPT를 쓰면 됩니다. 어느 쪽이든 이 부록의 방법은 똑같습니다. 화면 문구는 업데이트로 조금 다를 수 있습니다.

2단계: 파일로 달라고 부탁하기

Copilot은 부탁을 받으면 화면에 코드를 길게 보여 주거나 바로 미리보기를 띄우곤 합니다. 처음 보면 당황스럽기 때문에, 처음부터 "파일로, 다운로드 링크로 달라"고 못 박아 두는 것이 핵심입니다. 아래 프롬프트(Copilot에게 건네는 부탁의 글)를 복사하고 마지막 줄의 [만들고 싶은 것]을 내 내용으로 바꿔 보내세요. 대괄호는 지우고 내용만 남깁니다.

[만들고 싶은 것] 예시: "원두가 한 잔의 커피가 되기까지 5단계를 카드로 보여 주고, 카드를 누르면 설명이 펼쳐지는 페이지". 파일 이름을 index.html로 정하는 이유는 3장에서 설명한 대로, 주소를 열면 index.html이 첫 화면으로 보이는 약속 때문입니다.

그래도 코드가 화면에 나왔다면

당황하지 말고 "코드 말고 index.html 파일 다운로드 링크로 줘"라고 한 번 더 말하세요. 처음 결과가 마음에 들지 않는 것도 정상입니다. 1장에서 말한 "다시 부탁하기"가 이 교육의 핵심 기술입니다.

3단계: 파일 받기

  1. 다운로드 링크 누르기

    답변에 나온 index.html 링크를 누르면 파일이 내려받아집니다. 보통 내 PC의 다운로드 폴더에 저장됩니다.

  2. 받자마자 바로 저장

    Copilot이 만든 파일 링크는 시간이 지나면 열리지 않을 수 있습니다. 나중에 받으려고 미뤄 두지 말고 바로 내려받으세요.

  3. 링크가 열리지 않으면 zip으로

    링크를 눌러도 아무 일이 없거나 오류가 나면 아래처럼 다시 부탁합니다. Vercel은 zip 파일도 그대로 받기 때문에 압축을 풀지 않고 올려도 됩니다.

    zip을 받았는데 압축이 안 풀리거나 "손상된 파일"이라고 나오면 Copilot이 만든 zip이 깨진 것입니다. 그때는 zip을 포기하고 바로 아래의 "메모장으로 직접 저장하기"를 따라 하세요.

Copilot이 "파일을 만들 수 없다"고 하거나 zip도 안 될 때: 메모장으로 직접 저장하기

회사 설정에 따라 Copilot이 파일을 만들지 못할 수 있습니다. 그때는 "전체 코드를 코드 블록 하나로 보여줘"라고 부탁한 뒤 아래처럼 저장합니다.

  1. 코드 블록 오른쪽 위의 복사 버튼을 누릅니다.
  2. 메모장을 열고 붙여넣습니다.
  3. 파일 > 다른 이름으로 저장을 누릅니다.
  4. 파일 형식을 모든 파일로 바꾸고, 파일 이름을 index.html로 입력합니다.
  5. 인코딩이 UTF-8인지 확인하고 저장합니다.

파일 형식을 "텍스트 문서"로 둔 채 저장하면 실제 이름이 index.html.txt가 되어 웹페이지로 열리지 않습니다. 가장 많이 막히는 곳입니다.

4단계: 내 PC에서 열어 보고 고치기

받은 index.html을 더블클릭하면 브라우저에서 열립니다. 주소창에는 file:///C:/Users/...처럼 내 PC 경로가 보입니다. 아직 인터넷에 올라가지 않은 상태라 나만 볼 수 있습니다. 버튼을 눌러 보고, 브라우저 창의 가로 폭을 마우스로 좁혀 휴대폰 화면처럼 줄여 보고, 마음에 안 드는 곳을 찾아 Copilot에게 말합니다.

[바꿀 점] 예시: "제목을 더 크게, 배경은 더 차분한 남색으로", "카드를 누르면 부드럽게 펼쳐지게". 한 번에 하나나 둘씩 부탁하면 결과가 더 정확합니다.

새로 받은 파일 이름이 index (1).html이 될 수 있습니다

같은 이름의 파일이 이미 다운로드 폴더에 있으면 브라우저가 새 파일 이름 뒤에 (1)을 붙입니다. 다운로드 폴더의 예전 index.html을 지우거나 다른 폴더로 옮기고, 새 파일 이름을 index.html로 바꾼 뒤 다음 단계로 가세요. 준비물에서 파일 확장명 보기를 켜 두었다면 이름 끝이 .html로 보이는지 확인합니다. 확장명이 숨겨진 상태에서 index.html이라고 입력하면 실제 이름이 index.html.html이 될 수 있습니다.

5단계: Vercel Drop으로 첫 배포

  1. vercel.com/drop 열기

    Vercel에 로그인한 상태로 브라우저 주소창에 vercel.com/drop을 입력합니다. 가운데에 "Drop It. It's Live."라는 큰 제목이 있는 화면이 나옵니다. Vercel 대시보드에서 Projects, Add New..., Project 순서로 들어간 화면(vercel.com/new)의 아래쪽 끌어다 놓기 영역도 같은 기능입니다. 화면 문구는 업데이트로 조금 다를 수 있습니다. 파일이나 폴더를 끌어다 놓으라는 안내가 있는 화면이면 맞습니다.

  2. 파일을 끌어다 놓기

    다운로드 폴더의 index.html(또는 site.zip)을 마우스로 끌어 화면 가운데에 놓습니다. 끌어다 놓기가 어려우면 "Or choose a file or a folder." 안의 파란 file 글자를 눌러 파일을 고릅니다.

  3. 팀과 프로젝트 이름 정하기

    배포할 팀(내 Hobby 팀)을 고르고 프로젝트 이름을 입력합니다. 이 이름이 주소가 되므로 영어 소문자, 숫자, 하이픈으로 짓습니다. 흔한 이름은 이미 쓰는 사람이 있을 수 있으니 뒤에 숫자를 붙이세요(예: coffee-steps-27). 이름에는 회사명이나 개인정보를 넣지 마세요. 그다음 Deploy를 누릅니다. 배포 중에 "Root (/)"라는 메뉴가 나오면 index.html을 고르세요. "No root page"를 고르면 주소를 열었을 때 첫 화면이 404로 나옵니다.

  4. 내 주소 열어 보기

    배포가 끝나면 https://[프로젝트이름].vercel.app 모양의 주소가 나옵니다. 화면에 나온 주소를 그대로 눌러 열고, 휴대폰에서도 열어 보세요. 같은 이름을 다른 사람이 쓰고 있으면 내가 지은 이름과 끝이 조금 다른 주소가 만들어질 수 있으니, 동료에게 보낼 때는 열린 페이지의 주소창에서 복사해 보냅니다.

6단계: 고친 파일 다시 올리기 (주소 그대로)

고친 파일을 다시 vercel.com/drop에 놓으면 새 프로젝트와 새 주소가 생깁니다. 이미 공유한 주소를 그대로 두고 내용만 바꾸려면 아래처럼 합니다. 처음 한 번은 연습용 프로젝트로 주소가 유지되는지 먼저 확인해 보세요. 화면 문구는 업데이트로 조금 다를 수 있습니다.

  1. 올릴 폴더 만들기

    바탕화면에 새 폴더(예: my-site)를 만들고 고친 index.html을 넣습니다. 새 배포는 그때 올린 파일로 통째로 바뀌므로, 이미지를 쓰는 사이트라면 images 폴더도 같은 폴더에 함께 넣어야 합니다. zip으로 받았다면 먼저 압축을 풀어 그 내용을 넣습니다.

  2. 내 프로젝트 화면에 폴더째 끌어다 놓기

    Vercel 대시보드 왼쪽의 Projects를 누르고, 5단계에서 만든 프로젝트 이름을 누릅니다. 그 프로젝트 화면에 my-site 폴더를 통째로 끌어다 놓으면 그 프로젝트의 새 배포가 만들어지고, 주소는 그대로 유지됩니다. Vercel 안내가 폴더를 기준으로 하므로 폴더로 올리는 것을 기본으로 하세요.

  3. 내 주소에서 확인

    배포가 끝나면 같은 주소를 새로고침해서 바뀐 내용이 보이는지 확인합니다. 예전 화면이 그대로 보이면 Ctrl+F5로 강력 새로고침을 합니다. 올렸는데 새 프로젝트와 새 주소가 생겼다면 이 화면 드롭이 내 계정에서 안 되는 것이므로, 새 주소를 다시 공유하세요.

이미지 넣기 (선택)

페이지에 그림을 넣고 싶을 때는 두 가지 길이 있습니다. 먼저 방법 1로 해 보고, 사진 같은 이미지가 꼭 필요할 때 방법 2를 씁니다.

방법 1: 그림을 코드로 그려 넣기 (가장 확실)

아이콘, 간단한 일러스트, 도형 그림은 SVG라는 "코드로 그리는 그림"으로 파일 안에 넣을 수 있습니다. 이미지 파일이 따로 생기지 않아 index.html 하나로 끝나고, 확대해도 깨지지 않습니다.

[ ] 안은 내 내용으로 바꾸고 대괄호는 지웁니다. 예: "맨 위 제목 오른쪽"에 "김이 나는 커피잔".

방법 2: 이미지를 만들어 zip으로 받기

사진이나 그림 같은 이미지가 필요하면 Copilot에게 이미지를 만들게 하고, 웹페이지와 함께 zip 하나로 묶어 달라고 합니다. Vercel은 zip을 그대로 받습니다.

[ ] 안은 내 내용으로 바꿉니다. 이미지가 더 필요하면 설명 줄을 같은 모양으로 늘리세요. 이미지가 있는 사이트를 고칠 때는 4단계 프롬프트의 마지막 줄을 "전체 파일을 site.zip으로 새 다운로드 링크로 줘"로 바꿔 보내고, 압축을 푼 폴더째 6단계로 올립니다.

이미지 생성은 환경에 따라 안 될 수 있습니다

이미지를 만들 수 있는지는 회사 설정과 고른 모델에 따라 다릅니다. 이미지 생성에는 하루 사용 한도가 있을 수 있어 장수가 많으면 도중에 멈출 수 있으니, 먼저 1장만 만들어 보세요. 또 Copilot이 만든 이미지를 zip 안에 넣지 못하거나, 크기를 줄여 달라는 부탁이 지켜지지 않는 경우도 있습니다. 그럴 때는 아래처럼 직접 묶습니다.

  1. Copilot에게 이미지를 한 장씩 만들어 달라고 해서 각각 내려받습니다. 1MB가 넘게 크면 그림판이나 사진 앱에서 크기를 줄여 저장합니다.
  2. Copilot에게 "index.html은 이미지를 images/hero.png, images/step1.png 이름으로 불러오게 만들어 줘"라고 부탁해 새 파일을 받습니다.
  3. 바탕화면에 새 폴더(예: my-site)를 만들고, 그 안에 index.html과 images 폴더를 둡니다.
  4. 파일 확장명 보기를 켠 상태에서, 내려받은 이미지 이름을 index.html이 부르는 이름(hero.png 등)과 대소문자까지 똑같이 바꿔 images 폴더에 넣습니다.
  5. my-site 폴더를 통째로 Vercel Drop 화면에 끌어다 놓습니다.

zip이나 폴더로 받은 경우, 내 PC에서 미리 보려면 압축을 푼 뒤 그 안의 index.html을 더블클릭합니다.

나중에 링크를 누르니 안 돼요링크가 만료됐을 수 있습니다. 같은 대화에서 "파일을 다시 만들어 줘"라고 부탁합니다.
Copilot이 파일을 만들 수 없다고 해요3단계 아래의 "메모장으로 직접 저장하기"를 따라 합니다.
한글이 깨져요"UTF-8로 다시 만들어 줘"라고 부탁합니다.
답변이 중간에 끊겨요"이어서 계속해 줘"라고 하거나, 기능을 나눠 여러 번에 걸쳐 부탁합니다.

Vercel이 첫 화면(Root)을 고르라고 물어요zip 안에 폴더가 한 겹 더 있거나 파일 이름이 index.html이 아니라는 뜻입니다. 목록에서 index.html을 고르거나, index.html이 맨 위에 오게 다시 받습니다.
Vercel 화면에 빨간 오류가 나와요오류 문구를 복사해 Copilot에게 "쉬운 말로 원인과 해결 방법을 알려줘"라고 붙입니다. 문구에 이름이나 이메일이 보이면 지우고 붙입니다.
다시 올렸더니 주소가 바뀌었어요vercel.com/drop이 아니라 6단계처럼 대시보드의 내 프로젝트 화면에 폴더째 올립니다.
고쳐서 올렸더니 이미지가 사라졌어요새 배포는 올린 파일로 통째로 바뀝니다. 6단계에서 images 폴더도 함께 넣어 다시 올립니다.
이미지가 안 보여요index.html이 부르는 이미지 이름과 실제 파일 이름이 대소문자와 확장명(.png, .jpg)까지 똑같은지, images 폴더가 index.html 옆에 있는지 확인합니다. 내 PC에서는 열려도 Vercel 주소에서는 대소문자가 다르면 안 보입니다.
