오늘 배워볼 내용

Claude Code에게 지시하고, 바뀐 코드와 화면을 검토하며 인터랙티브 사이트 하나를 만들어 배포합니다. 사이트는 연습 무대이고, 목표는 AI 코딩 에이전트와 일하는 방식을 손에 익혀 실제 개발 업무에 가져가는 것입니다.

이 교육의 목표

코드를 직접 쓰는 대신 Claude Code에게 지시하고, 결과를 검토하고, 커밋 단위로 쌓아 가는 흐름을 처음부터 배포까지 한 번 해 봅니다. 연습 무대로 웹사이트를 고른 이유는 지시가 좋았는지를 화면으로 바로 확인할 수 있기 때문입니다. 같은 흐름이 6장에서 레거시 분석, 테스트 작성, 오류 원인 찾기 같은 실제 업무로 이어집니다.

오늘의 결과물

https://[프로젝트이름].vercel.app으로 열리는 인터랙티브 사이트 하나. 스크롤하면 장면이 바뀌고, 누르면 반응합니다.

진행 순서

장하는 일끝났을 때
2장 준비도구 설치, 저장소 만들기, Vercel 연결, 스킬 설치빈 사이트가 내 주소로 열리고, 새 세션에 스킬 4개가 보입니다
3장 완성작과 프롬프트완성작을 열어 보고 쓸 프롬프트를 고릅니다. 내 주제라면 브리프를 씁니다쓸 프롬프트 또는 brief-v2.md
4장 만들기한 번에 만들고, 검토하며 한 곳씩 다듬고, 브랜치로 비교한 뒤 배포합니다다듬은 사이트가 내 주소에 공개됩니다
5장 모션 영상 (선택)hyperframes로 10초 영상을 만들어 사이트에 넣습니다첫 화면에 소개 영상
6장 업무로 가져가기같은 방식을 개발 업무에 적용합니다내 업무에서 맡겨 볼 작업 하나

완성작 중 태양계 여행은 이미지 12장이 필요해 수업 뒤 과제로 권합니다.

준비물

  • Claude 유료 플랜(Pro 이상). 무료 플랜에서는 Claude Code를 쓸 수 없습니다.
  • GitHub 계정. Vercel은 2장에서 GitHub 계정으로 가입합니다.
  • Windows 또는 Mac PC. 회사 PC에서 설치가 막혀 있으면 미리 IT 담당자에게 확인합니다.

AI 사용 보안 수칙

이런 정보는 입력, 파일 첨부, 스크린샷 업로드 등 어떤 형태로도 AI에 넣지 마세요

1) 개인정보

  • 주민등록번호, 여권번호, 운전면허번호 등 고유식별정보
  • 성명, 연락처, 주소, 이메일 등이 합쳐져서 누구인지 알아볼 수 있는 정보
  • 건강 정보, 신용 정보, 금융 정보 같은 민감정보
  • 고객, 임직원, 구직자 등 다른 사람의 개인정보 전부

2) 인증정보

  • 비밀번호, API 키, 액세스 토큰, 인증서, 시크릿 키

3) 회사 기밀정보 (별도 승인을 받지 않은 경우)

  • 공개 전 재무 정보, 경영 전략, M&A 관련 자료
  • 계약서 원본, 고객사 기밀 자료, NDA(비밀유지계약) 대상 정보
  • 보안 등급이 붙은 문서(대외비 이상)
개발자가 특히 조심할 것
  • 회사 소스 코드, 쿼리와 스키마, 접속 정보(.env, 설정 파일의 계정과 비밀번호), 운영 데이터와 로그 속 개인정보는 회사가 승인한 도구와 절차 안에서만 다룹니다. 오늘 쓰는 개인 계정(Claude, GitHub, Vercel)에는 넣지 않습니다.
  • Vercel에 올린 사이트는 주소를 아는 누구나 봅니다. 사이트와 저장소에 회사 정보, 실제 이름과 연락처를 넣지 않습니다.
  • Claude가 명령 실행 허락을 구하면 명령을 읽고 판단합니다. 작업 폴더 밖 접근, 파일 삭제, 출처가 분명하지 않은 설치는 거절이 기본입니다.
