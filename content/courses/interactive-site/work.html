브랜치와 미리보기 배포로 비교기능 브랜치에서 작업하고 리뷰 후 병합

회사 코드에 쓰기 전에

승인된 도구와 계정에서만 씁니다
  • 회사 소스, 쿼리, DB, 로그를 외부 AI에 넣어도 되는지는 회사 정책이 정합니다. 오늘 만든 개인 계정에는 넣지 않습니다. 아래 예시는 공개된 오픈소스 저장소나 직접 만든 가상 코드로 먼저 연습합니다.
  • 접속 정보가 든 파일(.env, 운영 설정 파일)은 Claude가 읽지 못하게 작업 폴더에서 빼거나, Claude Code 설정의 deny 규칙으로 막습니다.
  • 회사 저장소에서는 권한 모드를 Manual이나 Accept edits로 두고, 운영 서버나 DB에 닿는 명령은 직접 확인합니다. Bypass permissions는 쓰지 않습니다.
  • 생성된 코드의 책임은 커밋한 사람에게 있습니다. 리뷰하고 테스트가 통과한 뒤에 병합합니다.
