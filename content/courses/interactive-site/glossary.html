용어 사전

Git, 터미널, 배포 같은 일반 개발 용어는 빼고, Claude Code와 이 교육에서 처음 만나는 용어만 모았습니다.

Claude Code

프롬프트
AI에게 보내는 요청이나 지시입니다. 개발에서는 원하는 동작, 변경 범위와 완료 기준을 함께 적습니다. 6장
컨텍스트 엔지니어링
작업에 필요한 코드, 문서와 도구 결과를 AI가 찾고 참고할 수 있게 구성하는 일입니다. 필요한 최신 정보를 고르고 연결합니다. 6장
하네스 엔지니어링
AI가 도구로 작업하고 실행 결과를 확인하며 실패를 고칠 수 있도록 환경과 절차를 구성하는 일입니다. 지침, 자료 접근, 실행 도구, 테스트와 권한이 함께 필요합니다. 6장
세션
Claude와의 대화 한 묶음입니다. 새 세션은 앞 대화를 기억하지 않고, 파일과 커밋 기록, CLAUDE.md를 다시 읽어 이어 갑니다. 4장
컨텍스트
Claude가 한 세션에서 참고하는 내용 전체(대화, 읽은 파일, 명령 결과)입니다. 길어질수록 앞부분을 놓치기 쉽고 사용 한도도 빨리 씁니다. 새 세션에서 이어 가거나 /compact로 요약합니다. 4장
사용 한도
요금제마다 일정 시간에 쓸 수 있는 양입니다. 큰 모델, 높은 노력 수준, 긴 컨텍스트일수록 빨리 줄어들고, 대화 중에 모델을 바꾸면 캐시를 다시 만드느라 더 씁니다. 데스크톱 앱은 모델 선택기 옆의 원형 표시, 터미널은 /usage로 확인합니다. 2장
노력 수준(effort)
답하기 전에 얼마나 깊이 생각할지 정하는 값입니다. 높을수록 결과가 좋아지지만 시간과 한도를 더 씁니다. 이 교육은 Extra high 기준입니다. 2장
권한 모드
Claude가 묻지 않고 해도 되는 범위입니다. Manual, Accept edits, Plan, Auto, Bypass permissions가 있습니다. 2장
Plan 모드
파일을 고치지 않고 읽고 조사해서 계획만 제안하는 권한 모드입니다. 큰 변경 전에 씁니다. 4장, 6장
CLAUDE.md
세션을 시작할 때마다 자동으로 읽히는 프로젝트 규칙 파일입니다. 기술 제약, 금지 사항, 확인 방법을 적고, 팀 저장소에 두면 같은 규칙을 함께 씁니다. 4장, 6장
되돌리기(/rewind)
터미널의 Claude Code에서 대화와 Claude가 고친 파일을 이전 시점으로 돌리는 명령입니다. Claude가 터미널 명령으로 바꾼 파일은 돌아오지 않으므로 커밋이 가장 확실한 안전장치입니다. 4장

확장

스킬
작업 지침(SKILL.md)과 부속 스크립트의 묶음입니다. Claude가 필요할 때 읽고, /스킬이름으로 직접 부를 수도 있습니다. 2장
플러그인과 마켓플레이스
플러그인은 스킬, 명령, 훅, MCP 서버 설정을 묶은 패키지이고, 마켓플레이스는 플러그인 목록을 담은 저장소입니다. 마켓플레이스를 등록한 뒤 설치하고 /플러그인:스킬로 부릅니다. 2장
훅(hook)
도구 실행 전후 같은 정해진 시점에 자동으로 도는 명령입니다. 플러그인이 설치할 수 있으므로 설치 전에 무엇을 실행하는지 확인합니다. 2장
MCP
외부 도구와 데이터를 Claude에 연결하는 표준 규격입니다. 예를 들어 REA는 Ghidra 같은 분석 도구를 MCP로 연결합니다. 부록 D

배포와 영상

Production과 Preview
Vercel에서 main에 푸시한 배포는 내 사이트 주소(Production), 다른 브랜치는 브랜치별 미리보기 주소(Preview)가 됩니다. 2장, 4장
배포 보호
Preview 주소를 Vercel 로그인으로 막아 두는 설정(Deployment Protection)입니다. 다른 사람에게 보낼 주소는 Production 주소입니다. 2장
prefers-reduced-motion
운영체제의 동작 줄이기 설정입니다. 완성작 프롬프트는 이 설정을 켠 사람에게 큰 움직임을 끄도록 요구합니다. 3장
hyperframes
HTML로 장면을 짜서 프레임 단위로 렌더해 MP4를 만드는 도구입니다. 5장
