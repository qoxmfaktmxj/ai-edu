업무 프롬프트 더 보기

공개 프롬프트 공유 사이트에서 업무에 쓸 만한 프롬프트를 골라, 설계 카드 기준으로 부족한 칸을 채워 다시 썼습니다. 그대로 Copilot에 써도 되고, 내 에이전트의 안내로 옮겨도 됩니다.

어떻게 골랐나

오픈프롬프트의 글 프롬프트 330개(2026년 10월 기준) 가운데 2025년 이후 글에서, 자주 반복하는 일이고 입력과 결과가 분명하며 회사에서 써도 안전한 것 네 개를 골랐습니다. 원문을 옮기지 않고 구조만 참고해 이 교육에 맞게 새로 썼습니다. 오픈프롬프트 이용약관에 따라 항목마다 원문 링크와 원저작자를 적었습니다.

1. 업무용 메일 답장

원문: GPT를 활용한 업무용 이메일 자동 작성 프롬프트 (원저작자 PRPT_코끼리, 2025-02-27)

고객 메일은 이름, 연락처, 계약 금액 같은 정보를 지우거나 바꾼 뒤 붙여 넣습니다.

2. 처음 쓰는 업무 서식 가이드

원문: 회사 업무 문서명을 입력하면 GPT가 문서 작성을 도와줍니다 (원저작자 PRPT_코끼리, 2025-03-07)

3. 사내 교육, 세미나 정리 노트

원문: 강의 스크립트로 '노션 복습노트' 자동 생성 (원저작자 오르트구름, 2026-01-29)

4. 웹 근거 동향 조사

원문: 이게 진짜 유행일까? 웹 근거로 검증하는 심층 트렌드 리서치 (원저작자 역동적 프롬프터5137, 2026-09-03)

조사 대상 칸에 회사 내부 정보를 넣지 마세요

웹 검색을 하는 요청은 내가 적은 단어가 검색어가 되어 바깥으로 나갈 수 있습니다. 출시 전 제품 이름, 고객사 이름, 내부 프로젝트 이름은 넣지 않고, 공개된 일반 용어로만 적습니다.

내 에이전트로 옮기기

자주 쓰게 된 프롬프트는 에이전트로 만들면 매번 붙여 넣지 않아도 됩니다. 카드의 '결과 형식'은 안내의 # 결과 형식으로, '꼭 지킬 것'은 # 꼭 지킬 것으로 그대로 옮기고, [대괄호] 입력 칸은 추천 프롬프트 문장으로 만듭니다. 방법은 5장과 같습니다.
