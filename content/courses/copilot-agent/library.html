업무 프롬프트 더 보기

공개 프롬프트 공유 사이트에서 업무에 쓸 만한 프롬프트를 골라, 설계 카드 기준으로 부족한 칸을 채워 다시 썼습니다. 그대로 Copilot에 써도 되고, 내 에이전트의 안내로 옮겨도 됩니다.

약 10분난이도 쉬움

어떻게 골랐나

오픈프롬프트에 올라온 글 프롬프트 330개를 2026년 10월에 살펴보고, 2025년 이후 글 가운데 아래 여섯 질문을 기준으로 네 개를 골랐습니다. 앞의 네 질문은 4장의 설계 카드와 같습니다.

기준질문
반복매주 또는 매번 하는 일인가
입력무엇을 붙여 넣는지 정해져 있나
결과형태와 분량이 정해져 있나
꼭 지킬 것숫자 보존, 없는 내용 표시 같은 사실 규칙이 있나
회사 사용고객 자료나 다른 사람의 개인정보를 넣게 유도하지 않나
Copilot웹 검색 없이 동작하나, 아니면 웹 검색이 필요한가

아래 카드는 원문을 옮긴 것이 아니라, 원문의 구조를 참고해 이 교육에 맞게 새로 쓴 것입니다. 원문은 각 항목의 링크에서 볼 수 있습니다. 오픈프롬프트 이용약관에 따라 원저작자를 함께 적었습니다.

1. 업무용 메일 답장

2. 처음 쓰는 업무 서식 가이드

3. 사내 교육, 세미나 정리 노트

4. 웹 근거 동향 조사

조사 대상 칸에 회사 내부 정보를 넣지 마세요

웹 검색을 하는 요청은 내가 적은 단어가 검색어가 되어 바깥으로 나갈 수 있습니다. 출시 전 제품 이름, 고객사 이름, 내부 프로젝트 이름은 넣지 않고, 공개된 일반 용어로만 적습니다.

내 에이전트로 옮기기

자주 쓰게 된 프롬프트는 에이전트로 만들면 매번 붙여 넣지 않아도 됩니다. 카드의 '결과 형식'은 안내의 # 결과 형식으로, '꼭 지킬 것'은 # 꼭 지킬 것으로 그대로 옮기고, [대괄호] 입력 칸은 추천 프롬프트 문장으로 만듭니다. 방법은 5장과 같습니다.
