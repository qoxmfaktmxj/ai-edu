써 보기

웹 검색으로 만든 PPT 보고서, PDF, 글 다듬기, 그림 설명을 차례로 받아 봅니다. 결과를 받을 때마다 숫자와 출처, 원문이 맞는지 확인하고, 마지막에 좋은 점과 아쉬운 점을 하나씩 적습니다.

할 일확인할 것
1. PPT 파일 받기숫자와 사례마다 출처가 있나, 확인 안 된 내용은 '확인 필요'인가
2. PDF로 저장로고와 띠, 도식이 PDF에도 나오나
3. 글 다듬기 (새 대화)숫자, 영어 약어, '검토해야 할 때'가 그대로인가
4. 그림 설명 받기 (새 대화)HTML 파일이 오고 장면마다 그림이 있나
5. 메모 카드 적기좋은 점 1개, 아쉬운 점 1개

1. PPT 파일 받기

2. PDF로 저장

  1. 내보내기 열기

    PowerPoint에서 받은 PPT를 연 채로 파일, 내보내기를 차례로 누릅니다.

  2. PDF/XPS 문서 만들기

    PDF/XPS 문서 만들기를 누르고 저장할 곳을 고른 뒤 게시를 누릅니다. 만들어진 PDF를 열어 로고와 띠, 도식이 그대로 나오는지 확인합니다.

Word나 한글 파일이 필요하면

같은 대화에서 "Word 파일로도 만들어 주세요"라고 하면 같은 내용의 .docx를 받을 수 있습니다. 한글 파일이 필요하면 "한글용으로 만들어 주세요"라고 합니다. 받은 파일을 한글에서 열어 '다른 이름으로 저장'으로 HWP를 고르면 됩니다. 한글용은 그림 대신 표로 머리글을 꾸밉니다.

3. 글 다듬기

4. 그림 설명 받기

5. 메모 카드 적기

메모장이나 종이에 두 줄만 적습니다. 아쉬운 점은 6장에서 '내가 추가할 규칙'이 됩니다.

좋은 점 예

  • 숫자마다 출처와 날짜를 달았다
  • 자료마다 다른 별 수를 두 값 모두 적었다
  • PDF까지 양식과 도식이 그대로 나왔다

아쉬운 점 예 규칙 후보

  • 결론 문장이 너무 길다
  • 사례와 시사점이 겹친다
  • 다듬은 글이 원문보다 길어졌다
