02

써 보기

가상 메모 하나로 보고서 파일, PDF, 글 다듬기, 그림 설명을 차례로 받아 봅니다. 결과를 받을 때마다 숫자와 상태가 원문 그대로인지 확인하고, 마지막에 좋은 점과 아쉬운 점을 하나씩 적습니다.

약 25분난이도 쉬움
분할 일확인할 것
0-101. 보고서 파일 받기숫자, 상태, 담당자를 바꾸거나 지어내지 않았나
10-142. PDF로 저장로고와 띠가 PDF에도 나오나
14-193. 글 다듬기 (새 대화)숫자, 영어 약어, '검토해야 할 때'가 그대로인가
19-234. 그림 설명 받기 (새 대화)HTML 파일이 오고 장면마다 그림이 있나
23-255. 메모 카드 적기좋은 점 1개, 아쉬운 점 1개

1. 보고서 파일 받기

아래 카드에는 요청 문장과 가상 메모가 함께 들어 있습니다. 복사 단추를 눌러 통째로 에이전트에게 보냅니다. 메모의 숫자와 내용은 교육용으로 지어낸 것이며 실제와 관계없습니다.

  1. 대화창 초안 읽기

    에이전트는 먼저 대화창에 보고서 초안을 보여 주고, 이어서 HTML 파일 링크를 줍니다. 1~2분 걸릴 수 있습니다. 초안에서 아래를 확인합니다.

    초안 확인 목록
    • 18명, 340건, 25분에서 4분, 82%, 월 약 280만 원이 원문과 같은가
    • '검토해야 할 때', 'SSO 연동을 추진'이 '완료했다', '확정했다'로 바뀌지 않았나
    • 메모에 없는 담당자나 기한을 지어내지 않았나. 없으면 '확인 필요'로 남아야 정상입니다
    • 작성자와 부서가 내 프로필로 채워졌다는 안내 한 줄이 있나

  2. HTML 파일 내려받아 열기

    답변 끝의 파일 링크를 눌러 내려받고, 파일을 더블클릭해 Edge로 엽니다. 위쪽에 회사 로고와 색 띠, 제목 아래에 결론 한 문장, 번호가 붙은 항목이 보입니다. 만들어진 파일은 내 OneDrive에도 저장됩니다.

파일 링크 대신 글만 왔다면

"HTML 파일로 만들어 주세요"라고 한 번 더 보냅니다. 그래도 파일이 오지 않으면 "HTML 코드로 보여 주세요"라고 부탁해, 받은 코드를 메모장에 붙이고 이름을 보고서.html로 저장합니다. 이때 파일 형식을 '모든 파일'로 바꿔야 .txt가 붙지 않습니다.

2. PDF로 저장

  1. 인쇄 창 열기

    Edge에서 보고서 HTML을 연 채로 Ctrl + P를 누릅니다.

  2. PDF로 저장 고르기

    프린터(대상) 목록에서 PDF로 저장을 고르고, 용지는 A4 그대로 둡니다. 오른쪽 미리 보기에 로고와 띠가 보이면 저장을 누릅니다.

Word나 한글 파일이 필요하면

같은 대화에서 "Word 파일로도 만들어 주세요"라고 하면 같은 내용의 .docx를 받을 수 있습니다. 한글 파일이 필요하면 "한글용으로 만들어 주세요"라고 합니다. 받은 파일을 한글에서 열어 '다른 이름으로 저장'으로 HWP를 고르면 됩니다. 한글용은 그림 대신 표로 머리글을 꾸밉니다.

3. 글 다듬기

대화창 위쪽의 새 대화를 눌러 대화를 새로 시작합니다. 앞 대화의 보고서 맥락이 섞이지 않게 하려는 것입니다. 아래 카드에는 메모의 '향후 계획' 단락이 들어 있습니다.

다듬기 확인 목록
  • 보고서 목차 없이 다듬은 글만 왔나
  • "검토해야 할 때"가 "검토한다"처럼 확정으로 바뀌지 않았나
  • SSO가 그대로 있나. 원문의 합쇼체(-습니다)가 유지됐나
  • "판단됩니다", "시사하는 바가 크다" 같은 상투적인 표현이 줄었나

4. 그림 설명 받기

다시 새 대화를 엽니다. 메모 본문에 RAG, 임베딩, 벡터 DB가 나왔습니다. 방금 다듬은 메모 속 낯선 단어를 바로 설명받는 흐름입니다.

장면 4~6개로 나뉜 HTML 파일이 옵니다. 장면마다 아이콘 그림과 짧은 설명이 붙어 있습니다. 그림 설명은 개념을 확인하려고 웹 검색을 쓸 수 있습니다. 결과에 숫자나 기간이 나오면 출처가 있는지 한 번 확인하세요.

5. 메모 카드 적기

메모장이나 종이에 두 줄만 적습니다. 아쉬운 점은 6장에서 '내가 추가할 규칙'이 됩니다.

좋은 점 예

  • 숫자를 하나도 바꾸지 않았다
  • 담당자가 없다고 '확인 필요'로 남겼다
  • PDF까지 양식이 그대로 나왔다

아쉬운 점 예 규칙 후보

  • 결론 문장이 너무 길다
  • 문제점과 향후 계획이 겹친다
  • 다듬은 글이 원문보다 길어졌다
