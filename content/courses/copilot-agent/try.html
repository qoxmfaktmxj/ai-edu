써 보기

웹 검색으로 만든 PPT 보고서, PDF, 글 다듬기, 그림 설명을 차례로 받아 봅니다. 결과를 받을 때마다 숫자와 출처, 원문이 맞는지 확인하고, 마지막에 좋은 점과 아쉬운 점을 하나씩 적습니다.

강사가 알려 준 링크로 문서 도우미를 엽니다.

할 일확인할 것
1. PPT 파일 받기숫자와 사례마다 출처가 있나, 확인 안 된 내용은 '확인 필요'인가
2. PDF로 저장로고와 띠, 도식이 PDF에도 나오나
3. 글 다듬기 (새 대화)숫자, 영어 약어, '검토해야 할 때'가 그대로인가
4. 그림 설명 받기 (새 대화)HTML 파일이 오고 장면마다 그림이 있나
5. 아쉬운 점 적기6장에서 규칙 한 줄로 바꿀 것 1개

1. PPT 파일 받기

2. PDF로 저장

PowerPoint에서 PDF로 내보낸 뒤, 로고와 띠, 도식이 PDF에도 그대로 나오는지 확인합니다. Word나 한글 파일이 필요하면 같은 대화에서 "Word 파일로도 만들어 주세요", "한글용으로도 만들어 주세요"라고 합니다.

3. 글 다듬기

4. 그림 설명 받기

5. 아쉬운 점 적기

받은 결과에서 아쉬운 점을 하나 적어 둡니다. 6장에서 이것을 규칙 한 줄로 바꿉니다.
