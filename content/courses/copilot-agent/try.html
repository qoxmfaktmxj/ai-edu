써 보기

가상 메모 하나로 보고서 파일, PDF, 글 다듬기, 그림 설명을 차례로 받아 봅니다. 결과를 받을 때마다 숫자와 상태가 원문 그대로인지 확인하고, 마지막에 좋은 점과 아쉬운 점을 하나씩 적습니다.

약 25분난이도 쉬움
분할 일확인할 것
0-101. 보고서 파일 받기숫자, 상태, 담당자를 바꾸거나 지어내지 않았나
10-142. PDF로 저장로고와 띠가 PDF에도 나오나
14-193. 글 다듬기 (새 대화)숫자, 영어 약어, '검토해야 할 때'가 그대로인가
19-234. 그림 설명 받기 (새 대화)HTML 파일이 오고 장면마다 그림이 있나
23-255. 메모 카드 적기좋은 점 1개, 아쉬운 점 1개

1. 보고서 파일 받기

2. PDF로 저장

  1. 인쇄 창 열기

    Edge에서 보고서 HTML을 연 채로 Ctrl + P를 누릅니다.

  2. PDF로 저장 고르기

    프린터(대상) 목록에서 PDF로 저장을 고르고, 용지는 A4 그대로 둡니다. 오른쪽 미리 보기에 로고와 띠가 보이면 저장을 누릅니다.

Word나 한글 파일이 필요하면

같은 대화에서 "Word 파일로도 만들어 주세요"라고 하면 같은 내용의 .docx를 받을 수 있습니다. 한글 파일이 필요하면 "한글용으로 만들어 주세요"라고 합니다. 받은 파일을 한글에서 열어 '다른 이름으로 저장'으로 HWP를 고르면 됩니다. 한글용은 그림 대신 표로 머리글을 꾸밉니다.

3. 글 다듬기

4. 그림 설명 받기

5. 메모 카드 적기

메모장이나 종이에 두 줄만 적습니다. 아쉬운 점은 6장에서 '내가 추가할 규칙'이 됩니다.

좋은 점 예

  • 숫자를 하나도 바꾸지 않았다
  • 담당자가 없다고 '확인 필요'로 남겼다
  • PDF까지 양식이 그대로 나왔다

아쉬운 점 예 규칙 후보

  • 결론 문장이 너무 길다
  • 문제점과 향후 계획이 겹친다
  • 다듬은 글이 원문보다 길어졌다
