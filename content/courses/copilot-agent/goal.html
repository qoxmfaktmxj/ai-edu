문서 도우미 써 보기

회사 Copilot에는 "규칙을 미리 알려 둔 Copilot", 즉 에이전트를 만드는 기능이 있습니다. 강사가 만든 문서 도우미 에이전트를 써 보고, 만든 과정을 확인한 뒤, 내 반복 업무를 맡길 에이전트를 직접 만듭니다.

이 교육의 목표

Copilot에게 부탁할 때마다 "목차는 이렇게, 숫자는 그대로"를 다시 적고 있다면, 그 설명을 한 번만 적어 두고 계속 쓰는 방법이 에이전트입니다.

문서 도우미가 하는 일

요청받는 결과
"보고서로 만들어 주세요"대화창 초안과 회사 양식(로고, 띠, 색)이 들어간 HTML 파일
"PPT로 만들어 주세요"회사 PPT 양식(표지, 띠, 바닥글)에 내용을 정리한 .pptx 파일. 표, 글, 차트와 도식은 내용에 맞게 선택
"글을 다듬어 주세요"대화창에 다듬은 글. 원문의 문체와 숫자는 그대로

AI 사용 보안 수칙

이런 정보는 입력, 파일 첨부, 스크린샷 업로드 등 어떤 형태로도 AI에 넣지 마세요

1) 개인정보

  • 주민등록번호, 여권번호, 운전면허번호 등 고유식별정보
  • 성명, 연락처, 주소, 이메일 등이 합쳐져서 누구인지 알아볼 수 있는 정보
  • 건강 정보, 신용 정보, 금융 정보 같은 민감정보
  • 고객, 임직원, 구직자 등 다른 사람의 개인정보 전부

2) 인증정보

  • 비밀번호, API 키, 액세스 토큰, 인증서, 시크릿 키

3) 회사 기밀정보 (별도 승인을 받지 않은 경우)

  • 공개 전 재무 정보, 경영 전략, M&A 관련 자료
  • 계약서 원본, 고객사 기밀 자료, NDA(비밀유지계약) 대상 정보
  • 보안 등급이 붙은 문서(대외비 이상)

써 보는 순서

문서 도우미를 엽니다. 아래 가상 메모로 PPT를 만들고, PDF로 저장한 뒤, 글 다듬기를 받아 봅니다. 결과를 받을 때마다 원문의 숫자, 조건과 진행 상태가 유지됐는지 확인하고, 마지막에 좋은 점과 아쉬운 점을 하나씩 적습니다.

할 일확인할 것
1. PPT 파일 받기숫자와 조건이 메모와 같나, 예정인 일을 완료로 바꾸지 않았나
2. PDF로 저장로고와 띠가 유지되고, 표와 글이 잘리지 않나
3. 글 다듬기 (새 대화)숫자, 영어 약어, '검토해야 할 때'가 그대로인가
4. 아쉬운 점 적기5장에서 규칙 한 줄로 바꿀 것 1개

1. PPT 파일 받기

이 문서 도우미는 보고서에 웹 검색 내용을 넣지 않고, 이번에 준 자료를 기준으로 씁니다. 아래 요청과 가상 메모를 함께 복사해 보냅니다.

PPT를 열어 다음을 확인합니다. 배치 검사에 통과했다는 안내가 있어도, 내용이 맞는지는 메모와 직접 대조합니다.

  • 적용 완료 480개와 정비가 필요한 120개가 구분돼 있나요?
  • 집행액 420만원, 미집행액 80만원, 별도 월 비용 5만원이 섞이지 않았나요?
  • 인건비 절감액을 만들거나, 예정인 전체 적용을 완료로 바꾸지 않았나요?
  • 제외 대상과 남은 문제도 본문에 있나요? 아이콘이 많아 표와 글을 읽기 어렵지는 않나요?

2. PDF로 저장

PowerPoint에서 PDF로 내보낸 뒤, 로고와 띠가 유지되고 표와 글이 잘리지 않는지 확인합니다. Word나 한글 파일이 필요하면 같은 대화에서 "Word 파일로도 만들어 주세요", "한글용으로도 만들어 주세요"라고 합니다. 한글용은 .docx 파일을 받아 한글에서 열고 HWP로 저장합니다.

4. 아쉬운 점 적기

받은 결과에서 아쉬운 점을 하나 적어 둡니다. 5장에서 이것을 규칙 한 줄로 바꿉니다.

아쉬운 점 예규칙으로 바꾸면
결론 문장이 너무 길다결론은 두 문장 이내로 쓴다
다듬은 글이 원문보다 길어졌다다듬은 글은 원문 길이를 넘기지 않는다
아이콘이 많아 내용이 잘 안 보인다표와 글만으로 충분하면 아이콘을 생략하고, 같은 의미의 아이콘을 반복하지 않는다
