05

만들기

설계 카드를 에이전트 빌더에 보내 초안을 받고, 구성 탭에서 안내를 확인하고 고친 뒤, 미리 보기로 한 번 시험하고 만듭니다.

1. 빌더 열기

  1. 에이전트 만들기 누르기

    Copilot 왼쪽 메뉴의 에이전트 영역에서 에이전트 만들기(또는 새 에이전트)를 누릅니다. 왼쪽에 빌더 화면, 오른쪽에 시험해 볼 수 있는 미리 보기 창이 열립니다. 화면 문구는 업데이트로 조금 다를 수 있습니다.

2. 설계 카드 보내기

3. 구성 탭에서 확인하고 고치기

  1. 이름과 설명

    구성 탭을 엽니다. 이름은 30자 이내로, 무슨 일을 하는지 보이게 짓습니다(예: 회의 메모 정리 도우미). 설명은 다른 사람이 보고 "나도 써 볼까" 판단할 수 있게 한두 문장으로 씁니다.

  2. 안내 읽기

    안내 칸을 끝까지 읽습니다. 설계 카드의 '꼭 지킬 것'이 빠졌거나 말이 바뀌었으면 직접 고쳐 넣습니다. # 역할, # 결과 형식 같은 제목으로 나뉘어 있는지도 확인합니다.

  3. 직접 고친 뒤에는 설명 탭으로 돌아가지 않기

    구성 탭에서 안내를 직접 고친 다음 설명 탭에서 빌더와 다시 대화하면, 빌더가 안내를 새로 써서 내가 고친 부분이 사라질 수 있습니다. 고칠 것이 더 있으면 구성 탭에서 직접 고칩니다.

  4. 지식 확인하기

    지식 칸에 웹 검색이나 회사 자료(OneDrive, Teams, 메일)가 켜져 있는지 봅니다. 빌더가 알아서 켜 두는 경우가 있습니다. 내 업무에 필요 없으면 끕니다. 붙여 넣은 자료만으로 하는 일이라면 모두 꺼도 됩니다.

  5. 추천 프롬프트 하나 넣기

    추천 프롬프트는 누르는 즉시 전송됩니다. 그래서 "아래에 붙여 넣을 회의 메모를 정리해 주세요. 메모를 기다릴게요"처럼, 문장만으로 뜻이 통하고 다음에 무엇을 보내야 하는지 알 수 있게 씁니다.

  6. 응답 모드 고르기

    대부분은 자동이면 충분합니다. 형식을 꼭 지켜야 하는 일인데 결과가 들쭉날쭉하면 깊이 생각하기로 바꿔 봅니다.
