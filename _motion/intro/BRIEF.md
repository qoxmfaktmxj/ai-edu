# 교육 소개 영상: 말로 시작해, 내 사이트로

20초, 1920x1080, 30fps, 무음 반복 재생. 사용자가 승인한 감독안에 따라 요청, 결과 확인, 수정 과정을 하나의 브라우저 창에서 이어 보여준다.

## 시간표

- 0~2초: 실제 별 입자가 모이는 화면. 이런 사이트도, 말로 만듭니다.
- 2~5초: 창이 오른쪽으로 줄어든다. 원하는 것을 설명하고. 별이 모여 문장이 되는 사이트를 만들어줘.
- 5~8초: 같은 창에 결과가 드러난다. 결과를 확인하며. 커서에 별 입자가 반응한다.
- 8~11초: 내 생각대로 완성합니다. 동그란 버튼을 네모로 바꿔줘. 같은 버튼의 모서리만 원형에서 사각형으로 바뀐다.
- 11~13초: 같은 창이 화면 전체로 커지고 별이 흩어졌다가 모인다.
- 13~15초: 별빛에서 둥근 관측등으로 연결한다. 심해 탐험.
- 15~17초: 관측등에서 지구로 연결하고 토성으로 이동한다. 태양계 여행.
- 17~20초: 마지막 천체 화면이 작아지며 세 작품으로 정리된다. 말로 시작해, 내 사이트로 완성합니다.

## 자산과 재현

- assets/process.mp4: public/examples/stardust의 실제 Canvas 화면. 오프닝 2.3초부터 13초를 캡처했다. 촬영 시간 6초와 11초에 포인터를 옮겨 별 입자가 반응하도록 했다. UI는 촬영 페이지에서만 숨겼다.
- assets/deep-sea.mp4: 사용자가 확정한 public/examples/deep-sea-dive의 덤보문어와 관측등. 기존 승인 촬영본을 재사용한다.
- assets/solar-travel.mp4: public/examples/space에서 지구를 고른 뒤 0.4초에 토성으로 이동했다. UI는 촬영 페이지에서만 숨기고 장면을 가운데 배치했다. 천체는 기존 예제의 AI 생성 이미지다.
- 세 포스터는 각 예제 촬영본에서 추출했다. 모든 촬영본은 1280x720, 30fps이며 MP4 키프레임은 1초 간격이다.
- 프롬프트 입력창, 사각형 단계 표시, 원형에서 사각형으로 바뀌는 시작 버튼은 학습 과정을 설명하는 영상 그래픽이다. 예제 사이트의 UI를 수정한 것은 아니다.
- Pretendard Variable은 기존 프로젝트의 SIL OFL 글꼴이며 GSAP도 기존 로컬 파일을 사용한다.

HyperFrames 0.8.152 플러그인 CLI로 검증하고 렌더링한다. 공개 파일은 public/assets/video/intro.mp4와 intro-poster.jpg이다. 중간 촬영 프레임과 검사 결과는 renders 및 .hyperframes에만 남긴다.
