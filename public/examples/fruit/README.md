# ONE FRUIT - 딸기, 한 알의 선명한 순간.

딸기 한 알을 주인공으로 한 소개 예제입니다. 순수 HTML/CSS/JS(ES 모듈), 빌드 과정 없음.
진입 경로: `/examples/fruit/` (교육 사이트 통합 배포, 경로 처리는 `../deep-sea/README.md` 의 배포 항목과 같음)

## 구성

- 첫 화면: 사진 버튼과 "가까이 보기"가 같은 동작(1.00 -> 1.04 -> 1.00, 400ms 후 관찰 구간으로 이동). 반복 클릭은 겹치지 않음.
- 관찰 구간: 통째, 반쪽, 단면, 접사 4장. 레이어를 겹쳐 두고 투명도로 교체. 아직 안 불러온 사진은 디코딩이 끝나고, 그때도 마지막 선택일 때만 표시.
- 몰입 구간: 데스크톱은 160vh sticky 안에서 1.00 -> 1.15 확대와 빛 띠 한 번 통과(스크롤 진행률에 연결, 역스크롤 시 같은 구도). 모바일은 일반 흐름, 최대 1.06.
- 마지막 구간: 그대로, 요거트와, 디저트로 선택에 따라 색과 문구 변경(이 페이지 안의 상태만).

## 사진 교체 위치

`assets/img/` 의 WebP 파일과 `index.html` 의 `data-photo` 이미지 4장, 사진 설명은 `js/data.js` 의 `PHOTOS`.

## 사진 출처

Wikimedia Commons. Ivar Leidus(통째, 반쪽, 접사, CC BY-SA 4.0), Nesnad(단면, CC BY 4.0). 크기 축소와 WebP 변환만 했습니다. 상세 링크는 페이지 하단 "자료 출처".
배경 제거(누끼)는 하지 않았습니다. 원래 스튜디오 배경이 있는 사진을 둥근 프레임에 넣었습니다.

## 네 스킬이 바꾼 것

- design-taste-frontend: 사진이 주인공인 비대칭 첫 화면(제목 11 : 사진 13), 사진 뒤 붉은 색 면을 반대로 기울인 앞뒤 레이어, 진한 배경과 크림 배경의 섹션 교대, 버튼은 알약형/프레임은 20px로 모양 규칙 통일.
- ui-ux-pro-max: 한글 지원 단일 글꼴(Pretendard) 조합. 대비 계산으로 크림 위 붉은 글자는 #E3283F(4.1:1) 대신 #C21632(5.6:1), 어두운 배경의 버튼은 코럴 바탕 + 버건디 글자(7.1:1)로 조정.
- hyperframes(hyperframes-animation 규칙 3개를 웹 입력에 맞게 적용): press-release-spring(사진 클릭 반응), theme-crossfade-morph(사진 교체와 취향 색 교체를 투명도/색 크로스페이드로), ambient-glow-bloom의 traveling sweep(접사 위 빛 띠를 스크롤로 한 번 통과).
- impeccable: 아직 정식 점검 전입니다. 첫 화면 제목이 3줄로 넘치던 것만 확인해 글자 크기와 열 비율을 고쳤습니다. 마지막 구간 디자인은 다시 검토 중입니다.
