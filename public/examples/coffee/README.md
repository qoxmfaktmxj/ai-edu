# ONE CUP - 한 잔이 되기까지. (연출 우선 버전)

`prompts/coffee_direction_first_prompt_ko.txt` (교육 사이트 5장 주제 4 프롬프트)로 만든 예제입니다.
원두 한 줌이 핸드드립 한 잔이 되기까지를 AI 생성 사진 6장과 그 위의 움직임으로 보여 줍니다.
순수 HTML/CSS/JS(ES 모듈), 빌드 과정 없음. 진입 경로: `/examples/coffee/`

## 구성

- 오프닝(약 10초, 자동 재생): 원두, 그라인더, 뜸들이기, 붓기 사진이 천천히 당겨지며 지나가고, 완성 사진 위로 김이 오르며 제목이 뜹니다. "건너뛰기", "오프닝 다시 보기". 스크롤하면 바로 끝납니다.
- 원두: "향 맡아 보기"로 원두 위에 향 줄기.
- 분쇄: "길게 눌러 갈기". 누르는 동안 사진이 미세하게 떨리고 가루가 흩날리며 손잡이 주변 게이지가 참. 떼면 멈추고 다시 누르면 이어짐.
- 준비: "필터 적시기"로 필터 위 물빛과 드리퍼 아래 물방울.
- 뜸들이기: "첫 물 붓기"로 기포가 오르고 가루가 살짝 부풀었다 가라앉음.
- 붓기: 물줄기의 빛, 방울, 표면 물결이 계속 움직이고, "길게 눌러 붓기" 동안 더 굵고 빨라짐.
- 완성: 잔 위의 김, "처음부터 다시", 정보 패널.
- 화면 아래 여섯 단계 바로가기, 현재 단계 표시.

## 파일

```
coffee/
  index.html      장면 마크업과 오버레이(김, 방울, 기포, 물줄기, 게이지)
  styles.css      색 토큰(:root), 반복 모션, 모바일 배치
  js/data.js      사진 경로, 사진 비율, 초점, 오버레이 좌표(사진 크기에 대한 0..1 비율), 이미지 출처
  js/scene.js     사진 프레임 배치(placeFrame), 오프닝, 길게 누르기, 물방울/물빛/기포
  js/app.js       오버레이 위치 계산, 스크롤과 단계 표시, 버튼 연결
  assets/img/     beans, grinder, setup, bloom, pour, cup (WebP)
```

- 사진은 화면을 덮되 장면마다 정한 초점(그라인더, 드리퍼, 잔)이 보이게 놓고, 오버레이는 같은 프레임 안에 사진 비율 좌표로 붙여서 화면 크기가 바뀌어도 어긋나지 않습니다.
- 휴대폰에서는 사진을 화면 위쪽에 덜 확대해 놓고 글과 버튼은 그 아래 어두운 영역에 둡니다.
- 길게 누르기는 마우스, 터치, 키보드(스페이스나 엔터를 누르고 있기) 모두 됩니다.
- 동작 줄이기 설정에서는 오프닝과 반복 모션을 멈추고 버튼 기능은 그대로 둡니다.

## 이미지

- 원두, 그라인더, 드리퍼 준비: Figma AI 이미지 생성(gemini-3.1-flash-image)
- 뜸들이기, 붓기, 완성: ChatGPT 이미지 생성
- AI 생성 이미지라 실제 도구와 모양이 다를 수 있다고 페이지 정보 패널에 밝혔습니다.
