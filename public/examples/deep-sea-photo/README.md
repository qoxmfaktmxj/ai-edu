# LUMEN - 빛을 만드는 바다. (연출 우선 버전)

`prompts/deep_sea_direction_first_prompt_ko.txt` (교육 사이트 5장 주제 2 프롬프트)로 만든 심해 탐험 예제입니다.
같은 이야기와 코드를 두 가지 이미지로 만들었습니다.

- `/examples/deep-sea-photo/` 실제 사진판: NOAA 퍼블릭 도메인 사진과 Wikimedia Commons CC 사진
- `/examples/deep-sea-ai/` AI 생성 이미지판: Figma AI 이미지 생성(gemini-3.1-flash-image, 펠리칸장어와 덤보문어는 gpt-image-2.5)

두 폴더는 `js/data.js` 의 `ASSETS`, `CREDITS`, `VERSION` 과 `assets/img/` 만 다릅니다. 나머지 파일은 같습니다.

## 구성

- 오프닝(약 12초, 자동 재생): 어둠 속에서 덤보문어, 펠리칸장어, 초롱아귀, 아톨라해파리, 샛비늘치가 차례로 스쳐 가고, 수면의 빛으로 떠올라 제목이 뜹니다. "건너뛰기", "오프닝 다시 보기". 스크롤을 시작하면 바로 끝납니다.
- 햇빛층(정어리): 화면을 누르거나 "물결 일으키기"로 물결.
- 박명층(샛비늘치): 낮/밤 버튼으로 무리가 깊은 곳과 얕은 곳을 오감.
- 아톨라해파리: 누르면 파란 빛이 몸 둘레를 돎(도둑 경보).
- 초롱아귀류: 어둠 속에 미끼 빛만 보이다가 관측등을 켜면 몸이 드러남(데스크톱은 마우스를 따라감).
- 펠리칸장어: 스크롤에 따라 긴 몸이 화면을 가로지름.
- 덤보문어: 마지막 관측 지점. 고정된 채 마지막 도감 목록이 위로 올라옴.
- 해양설 입자는 스스로 천천히 가라앉고, 내려갈수록 위로 흘러갑니다. 깊어질수록 잘 보입니다.
- 모든 생물에 도감 카드(학명, 알려진 서식 깊이, 크기, 특징, 출처). 사실 정보는 MBARI, NOAA, Australian Museum, WHOI 기준이며 출처에 없는 수치는 적지 않았습니다.

## 파일

```
index.html      장면 마크업(두 버전 같음)
styles.css      레이아웃, 스크롤 연출(--p), 반복 모션, 모바일
js/data.js      SCENES(수심 구간), ASSETS(이미지와 합성 방식, 미끼/꼬리 빛 위치), CREDITS, SPECIES(도감)
js/scene.js     오프닝 타임라인(Web Animations), 해양설 캔버스, 물결, 경보 빛
js/app.js       이미지 적용, 스크롤과 수심, 버튼과 포인터, 도감 카드
```

## 모션 감소와 접근성

- 동작 줄이기 설정이면 오프닝을 재생하지 않고 마지막 장면만 보여 주며, 유영/기포/해양설 흐름을 멈춥니다. 버튼 기능(낮/밤, 경보, 관측등)은 그대로 쓸 수 있습니다.
- 반복 모션은 화면에 보이는 장면에서만 돌고, 탭이 숨겨지면 해양설도 멈춥니다.
- 모든 조작은 버튼이라 키보드로 쓸 수 있습니다. 휴대폰에서는 글이 화면 아래, 생물이 위에 오도록 배치했습니다.

## 배포

교육 사이트(Next.js) `public/examples/` 로 함께 배포됩니다. `next.config.ts` 의 examples 전용 리다이렉트로 상대 경로가 풀립니다.

## 확인한 것 (로컬 Next dev 서버, Chromium 헤드리스)

- 1440x900, 390x844(터치), 모션 감소에서 오프닝 재생과 종료, 여섯 장면 수심(80, 600, 1,300, 1,900, 2,600, 3,300, 맨 아래 4,000m), 물결, 낮/밤, 경보, 관측등, 도감 카드 열기/닫기
- 1,300m에서 새로고침 뒤 같은 수심, 오프닝은 다시 재생하지 않음
- 콘솔 오류 없음, 404 없음
