# ORBIT - 태양계를 건너는 여행. (연출 우선 버전)

`prompts/space_direction_first_prompt_ko.txt` (교육 사이트 5장 주제 3 프롬프트)로 만든 예제입니다.
태양에서 명왕성까지 열 개 천체를 골라 날아가 봅니다. 순수 HTML/CSS/JS(ES 모듈), 빌드 과정 없음. 진입 경로: `/examples/space/`

## 구성

- 오프닝(약 12초): 지구 궤도의 새벽, 별이 늘어나는 비행과 함께 아홉 천체가 스쳐 가고, 태양이 다가오며 제목. "건너뛰기", "여행 시작", "오프닝 다시 보기".
- 아래 태양계 지도, "이전 천체"/"다음 천체", 키보드 왼쪽/오른쪽 화살표로 이동. 이동할 때 별이 늘어나는 비행 전환. 연속으로 눌러도 마지막에 고른 천체로 도착.
- 주소 끝 `#mars` 처럼 천체 이름을 붙이면 그 천체에서 바로 시작하고, 새로고침해도 유지.
- 천체마다 행동: 태양 "홍염 보기", 지구 "하루 돌려 보기", 목성 "대적점 확대", 토성 "고리 확대", 천왕성 "자전축 보기", 지구를 뺀 모든 천체 "지구와 크기 비교"(실제 지름 비율, 지구보다 작으면 그 천체를 줄여서 표시).
- 천체를 끌면 살짝 기울어지고, 마우스를 움직이면 별 배경이 조금 따라 움직입니다.
- 정보 카드: 지름, 태양과의 거리, 하루, 1년, 위성 수, 사실 2개, NASA 출처 링크.

## 파일

```
space/
  index.html      화면 구조(배경, 천체, 정보 패널, 지도, 오프닝)
  styles.css      레이아웃, 반복 모션, 모바일 배치
  js/data.js      BODIES(천체별 정보와 출처, 이미지 속 원반 비율), 이미지 출처
  js/scene.js     별 비행 캔버스(warp), 오프닝 타임라인, 이동 전환
  js/app.js       지도, 이동, 천체별 행동, 크기 비교, 주소(#천체) 처리
  assets/img/     천체 10장(검은 배경을 투명하게 처리한 WebP), stars, orbit
```

## 이미지

- ChatGPT로 생성한 이미지입니다(천왕성과 명왕성은 여러 장 중 실제 모습에 가까운 것을 골랐습니다).
- 검은 배경은 투명하게 바꿨습니다. 행성 원반은 원 모양으로 따내고, 태양과 토성 고리는 밝기를 기준으로 투명도를 줬습니다. 화면에서 블렌드로만 지우면 이 구조에서는 검은 사각형이 남았기 때문입니다.
- 정보 패널에 "AI 생성 이미지라 실제 모습과 다를 수 있다", "크기와 거리는 연출이며 크기 비교만 실제 비율"이라고 밝혔습니다.

## 정보 출처

각 천체의 science.nasa.gov facts 페이지와 NASA Planetary Fact Sheet. 위성 수는 페이지 기준을 함께 적었습니다(목성 115개는 NASA 목성 페이지, 토성 274개는 2025년 3월 기준).
