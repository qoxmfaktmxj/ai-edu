# 후쿠오카 여행 다이어리: 요청하고, 보고, 다시 고치기

이 결과물은 한 번의 요청으로 완성하지 않았습니다. 첫 화면을 열어 보고 원하는 분위기와 다른 점을 말했고, 참고 영상을 함께 보면서 디자인을 다시 잡았습니다. 그 뒤 실제 지도도 넣어 보고, 전체 분위기에 맞춰 그림 지도로 다시 바꾸면서 글자 크기와 버튼 모양을 차례로 수정했습니다.

## 이 예시를 보여주는 이유

AI를 업무에만 써야 하는 것은 아닙니다. 여행 계획이나 취미처럼 내가 관심 있고 결과를 판단할 수 있는 일에서 자주 써보세요. 원하는 것을 말하고, 결과를 살펴보고, 마음에 들지 않는 부분을 다시 부탁하는 과정에 익숙해지는 것이 중요합니다.

이 후쿠오카 다이어리도 그런 연습입니다. AI와 함께 만들고 고치면서 어떤 정보를 줘야 하는지, 무엇을 직접 확인해야 하는지 감을 잡고, 일상에서 쌓은 경험을 업무에도 가져가 보세요.

## 결과를 보며 고친 과정

> 저도 처음부터 이렇게 만들지는 않았어요. 처음 나온 화면을 보고 원하는 느낌이 아니어서 참고 영상을 보여줬고, 결과를 보면서 지도와 글자 크기, 버튼 모양을 계속 고쳤습니다. 한 번에 완벽한 프롬프트를 쓰는 것보다, 나온 결과를 직접 보고 다음 요청을 해보는 게 중요했습니다.

아래 1~5번은 결과를 보며 이어서 요청할 수 있는 예시입니다. 마지막 긴 프롬프트는 여러 차례 수정하며 정한 조건을 모은 최종 재현용 요청입니다.

## 1. 처음에는 원하는 결과부터 말하기

```text
후쿠오카 3박 4일 여행 다이어리를 HTML 파일로 만들어줘.
성인 2명이고, 음식과 카페, 산책, 쇼핑을 좋아해. 하카타역 근처 숙소를 기준으로 첫날 오후 도착, 마지막 날 오후 출국을 가정해줘.
날짜와 항공편, 숙소는 아직 정해지지 않았어.

핑크 Y2K와 다이어리 꾸미기 분위기로, 보는 재미가 있었으면 좋겠어.
날짜별 일정, 준비물 체크리스트, 금액을 바꾸면 합계가 계산되는 예산표를 넣어줘.
확인하지 않은 영업시간이나 가격은 만들어내지 마.
설치 없이 브라우저에서 열 수 있는 HTML 파일로 줘. 먼저 첫 결과를 보고 수정할 부분을 이야기할게.
```

## 2. 결과가 다르면 참고 화면으로 구체화하기

```text
첫 결과를 보니 내가 원한 느낌과 달라. 첨부한 표지, 지도, 일정 카드 화면을 참고해줘.
큰 글자와 그림이 좌우로 나뉜 소개 페이지보다, 휴대폰에서 길게 내려보는 다꾸 화면을 원해.

제목은 Fukuoka / with / love.를 크게 쌓고, 흰색 외곽선과 진한 그림자를 넣어 스티커처럼 만들어줘.
핑크 도트 배경, 호피 띠, 글리터 별과 리본, 폴라로이드의 재질을 살려줘.
일정은 분홍색 제목 표시줄이 있는 옛날 컴퓨터 창 모양으로 바꿔줘.
참고 이미지 속 인물과 이름은 가져오지 말고, 제공한 여행 콜라주를 사용해줘.

기존 여행 조건과 준비물, 예산 기능은 유지해줘. 고친 HTML 전체를 새 파일로 줘.
```

## 3. 지도를 비교하고 분위기에 맞게 바꾸기

```text
실제 지도를 넣어 보니 전체 다꾸 분위기와 어울리지 않아. 지도 부분을 직접 그린 듯한 Y2K 그림 지도로 바꿔줘.
하늘색 바다, 연분홍 육지, 굵고 조금 불규칙한 선, 스티커 같은 한글 장소 이름과 핀을 사용해줘.
날짜를 선택하면 그날의 방문 순서를 점선 화살표로 보여주고, 장소를 누르면 설명이 나오게 해줘.
정확한 축척이나 실제 길찾기 경로인 것처럼 표현하지 마.
실제 위치를 확인할 수 있도록 장소별 Google 지도 링크는 남겨줘.
지도 창과 장소 버튼의 모서리는 약 8px로 유지하고, 다른 화면과 기능은 바꾸지 마.
```

## 4. 작은 모양도 캡처로 짚어 수정하기

```text
첨부한 화면에서 버튼과 걷는 양 배지 등이 너무 둥글어.
여행 기간 배지와 여행 다이어리 펼치기, 날짜 선택, 지도 아래 장소 선택, 상세 지도로 이동, 다녀옴, 준비물 전체 해제 버튼을 모서리 반경 약 8px의 살짝 각진 사각형으로 바꿔줘.
테두리, 그림자, 글자, 선택된 핫핑크 색과 눌렀을 때 동작은 유지해줘.
걷는 양과 완료 배지, 일정 카드, 지도 창, 준비물과 예산 상자도 모서리 반경 약 8px로 통일해줘. 표지의 글자와 그림, 일정 내용은 바꾸지 마. 휴대폰에서 버튼이 잘리거나 겹치지 않는지 확인해줘.
```

## 5. 수정본을 다시 열어 확인하기

```text
수정한 HTML을 기준으로 날짜 선택, 그림 지도 동선과 장소 선택, 다녀옴 표시, 준비물 체크와 초기화, 예산 합계가 여전히 작동하는지 확인해줘.
작은 휴대폰 화면에서 글자가 읽히고 버튼이 겹치지 않는지도 확인해줘.
실행해서 확인할 수 없는 부분은 확인했다고 말하지 말고 내가 직접 볼 항목으로 알려줘.
수정한 전체 HTML을 새 파일 이름으로 제공해줘.
```

## 참고 이미지와 소재 준비

표지, 지도, 일정 카드 캡처 3장과 여행 콜라주 PNG를 함께 전달합니다. 참고 캡처는 이 여행 다이어리의 화면입니다. 콜라주는 AI가 생성한 여행 분위기 이미지입니다.

이 HTML은 Codex로 제작하고 여러 번 수정한 예시입니다. 같은 요청을 사용하더라도 결과는 달라질 수 있으므로, 파일을 열어 보고 필요한 부분을 다시 요청하세요.

## 최종 모양을 다시 만들 때 쓰는 통합 프롬프트

아래는 처음 보냈던 단 한 번의 요청이 아닙니다. 지금 결과의 조건을 한곳에 모아 다시 제작할 때 참고하도록 정리한 요청입니다. 참고 이미지와 콜라주를 첨부한 뒤 사용하고, 결과를 받아 다시 확인합니다.

```text
첨부한 참고 이미지 3장을 기준으로 후쿠오카 3박 4일 여행 다이어리를 만들어줘.
1번은 표지, 2번은 지도, 3번은 일정 카드야.
예쁜 일반 여행 소개 페이지가 아니라, 참고 화면처럼 핑크색 스티커와 질감이 풍부한 모바일 다꾸 웹페이지를 원해.

너의 역할은 여행 일정 편집자이자 웹 디자이너야.
참고 이미지의 구성, 제목의 모양, 테두리, 장식 밀도와 모바일 화면 비율을 먼저 살펴보고 구현해줘.
사진 속 인물과 이름, 전화 상태 표시줄, 카카오톡 닫기 버튼은 복제하지 마.
여행지와 내용은 아래 조건에 맞춰 후쿠오카로 바꿔줘.

[여행 조건]
- 성인 2명, 3박 4일, 하카타역 인근 숙소를 가정해줘.
- 날짜, 항공편과 실제 숙소는 미정이야. 예약이 끝난 것처럼 쓰지 마.
- 첫날 오후 도착, 마지막 날 오후 출국을 가정하고 공항 이동에 여유를 줘.
- DAY 1은 하카타와 구시다신사 주변, DAY 2는 오호리공원과 텐진,
  DAY 3은 다자이후, DAY 4는 하카타역 주변에서 마무리하는 흐름이야.
- 음식, 카페, 산책, 가벼운 쇼핑을 좋아해. 이동과 휴식도 일정에 넣어줘.
- 날짜가 정해지지 않았으므로 실제 날씨, 항공편, 예약 가능 여부를 만들어내지 마.
- 장소 정보는 공식 관광 안내를 우선 확인해줘. 확인하지 않은 영업시간과 요금은 방문 전 확인으로 표시해줘.
- 시각과 이동시간은 계획용 예시, 예산은 사용자가 정한 배분 예시로 구분해줘.

[화면 구성: 참고 이미지의 형태를 우선해줘]
- PC에서도 좁은 다이어리 한 권을 펼쳐 놓은 세로 화면으로 보여줘.
- 본문은 최대 약 720px로 하고, 휴대폰에서는 화면 너비에 맞춰줘.
- 제목 왼쪽, 그림 오른쪽으로 나누는 일반적인 2열 소개 화면은 사용하지 마.
- 전체 배경은 분홍색이고 작은 도트와 반짝이는 별이 반복되는 종이 느낌이야.
- 페이지 위아래와 메뉴 경계에는 핫핑크 바탕의 검은 호피 무늬 띠를 넣어줘.
- 과하게 정돈된 아이보리 잡지나 기업 홈페이지 느낌으로 바꾸지 마.

[표지와 글자]
- 표지는 Fukuoka / with / love.를 세 줄로 크게 쌓아줘.
- 제목은 둥글고 두꺼운 복고풍 기울임 글자. 흰색의 두꺼운 외곽선과 진한 자주색의 단단한 그림자로 오려 붙인 스티커처럼 보여줘.
- 핫핑크, 라벤더, 하늘색을 줄마다 다르게 사용해줘.
- 가능한 경우 Shrikhand 같은 굵은 장식 글꼴을 사용하고 파일 안에 포함해줘.
- 짧은 한글 메모는 손글씨 느낌을 낼 수 있지만, 일정 본문은 16px 이상의 읽기 편한 글꼴을 써줘.
- 부제는 먹고, 걷고, 사랑하는 후쿠오카.
- 여행 기간은 3 NIGHTS / 4 DAYS, 날짜는 아직 미정으로 표시해줘.
- 실제 인물 사진 대신 후쿠오카 여행 분위기의 야경과 음식 이미지, 폴라로이드, 테이프, 글리터 별, 리본, 나비, 카메라 장식을 사용해줘.
- 글리터와 홀로그램, 광택이 있는 스티커의 재질이 보여야 해. 단순한 삼각형이나 도형 몇 개로 만든 도시 그림으로 대체하지 마.
- 제공한 콜라주 이미지가 있으면 그대로 활용해줘. AI로 만든 이미지는 여행 분위기 이미지라고 표시하고 실제 장소를 촬영한 사진처럼 소개하지 마.
- 이미지를 만들거나 사용할 수 없다면 그 한계를 먼저 밝혀줘. 깨진 이미지 주소는 넣지 마.

[지도 창]
- 분홍색에서 보라색으로 이어지는 제목 표시줄과 굵은 테두리를 넣고, 제목은 FUKUOKA_MAP.exe로 해줘.
- 지도는 직접 낙서한 듯한 Y2K 그림 지도로 만들어줘. 하늘색 바다와 물결, 연분홍 육지, 굵고 약간 불규칙한 해안선, 스티커 같은 한글 장소 이름과 핀을 사용해줘.
- 후쿠오카공항, 하카타역, 구시다신사, 오호리공원, 텐진과 다이묘, 다자이후를 구분해 보여줘.
- 날짜를 고르면 그날의 방문 순서를 점선 화살표로 연결하고, 해당 장소 핀을 강조해줘.
- 그림의 핀과 지도 아래 장소 버튼을 누르면 같은 장소 설명이 나오게 해줘.
- 지도 아래 장소 버튼은 방문 순서대로 나열하고, 선택 상태가 보이게 해줘.
- 이 그림은 정확한 축척 지도나 실제 도로 경로가 아니야. 실제 위치와 길찾기는 별도의 한국어 Google 지도 링크에서 확인하게 해줘.
- 외부 지도 임베드나 지도 API는 사용하지 마. 그림 지도 자체는 인터넷 없이 작동해야 해.
- 작은 화면에서 장소 이름끼리 겹치거나 장식에 가려지지 않게 해줘.

[메뉴와 일정 카드]
- 날짜별 메뉴는 스크롤해도 화면 위쪽에 남아 있게 해줘.
- DAY 1, DAY 2, DAY 3, DAY 4, 준비물, 예산을 손가락으로 누르기 쉽게 만들어줘.
- 여행 기간 배지, 여행 다이어리 펼치기 버튼, 날짜 선택, 장소 선택, 상세 지도로 이동, 다녀옴, 준비물 전체 해제 버튼은 모서리 반경 약 8px의 살짝 각진 사각형으로 만들어줘. 캡슐처럼 둥글게 만들지 마.
- 버튼의 굵은 테두리, 그림자, 선택된 핫핑크 상태와 44px 이상의 높이는 유지해줘.
- 걷는 양과 완료 배지, 일정 카드, 지도 창, 준비물과 예산 상자, 출처 안내도 모서리 반경 약 8px로 통일해줘. 장식용 하트와 스티커는 유지해줘.
- 메뉴가 길면 메뉴 영역만 옆으로 넘길 수 있게 하고 페이지 전체에 가로 스크롤이 생기지 않게 해줘.
- 날짜를 바꾸면 일정과 그림 지도의 동선, 장소 버튼이 함께 바뀌어야 해.
- 일정 카드는 옛날 컴퓨터 창 모양으로, 시간은 제목 표시줄에 넣고 장소는 굵은 한글로 보여줘.
- 카드 왼쪽에는 점선과 하트 장식을 이용해 하루의 순서가 이어지게 해줘.
- 본문은 흰색 또는 매우 연한 분홍색 줄노트처럼 표현해줘.
- 장소, 짧은 설명, 이동과 휴식, 상세 확인, 지도 검색 링크를 넣어줘.
- 다녀옴 버튼을 제공한다면 누를 때 상태가 실제로 바뀌어야 해.
```
